# 🐉 Görünmez Ejderha Besleme Protokolü (GEBP)

## Resmi Bilimsel Dokümantasyon

Bu proje, **Görünmez Ejderha Besleme Protokolü**'nün (GEBP) resmi uygulamasıdır.  
Dünya çapında sadece 3 kişi tarafından anlaşılan, ultra-gizli ve son derece profesyonel bir sistemdir.

### Neden Bu Proje?

Görünmez ejderhalar, modern yaşamın en kritik sorunlarından biridir.  
Onları beslemezseniz:
- Wi-Fi sinyali zayıflar
- Kahve daha hızlı soğur
- Çoraplar kaybolur
- Pazartesi günleri daha uzun sürer

Bu yazılım, görünmez ejderhanızı **bilimsel yöntemlerle** beslemenizi sağlar.

### Kurulum

```bash
pip install hiçbir-şey  # Zaten Python yeterlidir
python ejderha_besleyici.py
```

### Kullanım

Programı çalıştırın.  
Menüden seçim yapın.  
Ejderhanızı besleyin.  
Dünyayı kurtarın.

### Önemli Uyarılar

- Ejderhayı günde 3 kereden fazla beslemeyin. Aşırı beslenme görünmezlik seviyesini artırabilir.
- Et yemeği vermeyin. Sadece soyut kavramlar ve duygusal destek kabul eder.
- Bu yazılımı çalıştırırken arkanızı dönmeyin. Ejderha sizi izliyor olabilir.

### Lisans

Kopyalayabilirsiniz ama kimseye söylemeyin.
